Hospital Appointment PHP

A simple, modular Hospital Appointment & Patient Management System built with PHP and MySQL.
This system provides core features for managing doctors, patients, and appointment bookings via a clean web interface.

🚀 Key Features

Patient registration & login

Doctor profiles & scheduling

Appointment booking and management

Configurable database setup

Lightweight and extensible for further development

🧠 Built With

PHP (core backend)

MySQL (data persistence)

HTML/CSS for UI

Modular project structure for easy customization

📦 Installation

Clone this repository

git clone https://github.com/shishir-kuet/Hospital-Appointment-PHP.git
cd Hospital-Appointment-PHP

Configure Database

Create a MySQL database

Import any provided SQL schema (or generate tables via scripts in /config)

Set up config

Update DB credentials in auth.php or /config

Launch on local server

With XAMPP / WAMP / LAMP:

Place folder in htdocs or equivalent

Start Apache and MySQL

Visit: http://localhost/Hospital-Appointment-PHP

🧩 How It Works

Users can register as patients and request appointments.

Admins/Doctors manage schedules and check bookings.

Simple, clear PHP logic with minimal dependencies.

🛠 Customize

Want to add features like email notifications, admin dashboards, or API support?
The modular structure makes it easy to extend and scale.
